# Learning defense

Read the project requirements, architecture, ADRs, evidence pack, and `docs/ASSESSMENT.md`. Ask one question at a time about an invariant, failure path, transaction boundary, or credible alternative. Wait for the learner's answer before explaining or moving on.

Probe with a changed requirement or failure scenario the learner has not rehearsed. Ask them to connect their answer to observable evidence and to state what remains uncertain. Do not disclose the intended answer during the examination.

After the exchange, score the six assessment dimensions from 0–4 with evidence for each score. State gaps and a concrete next exercise. If evidence is missing, say so rather than treating a confident explanation as proof.
